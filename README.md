# 📊 Data Analytics Dashboard

A responsive and interactive **Data Analytics Dashboard** built with Python, Dash, Plotly, and Pandas. The dashboard provides visual insights into sales, revenue, profit, products, categories, and regional performance.

## 🚀 Live Demo

👉 https://data-analytics-v7pk.onrender.com/

## ✨ Features

- 📊 Interactive data analytics dashboard
- 💰 Revenue and profit analysis
- 📈 Revenue trend visualization
- 🥧 Category-wise sales analysis
- 📦 Product performance analysis
- 🌍 Region-wise performance analysis
- 🔍 Interactive filters
- 📋 Detailed data table
- 💡 Business insights
- 📱 Responsive dashboard interface

## 🛠️ Technologies Used

- Python
- Dash
- Dash Bootstrap Components
- Plotly
- Pandas
- NumPy
- OpenPyXL

## 📌 Dashboard Includes

- Key Performance Indicators (KPIs)
- Revenue Analysis
- Profit Analysis
- Category Performance
- Product Performance
- Regional Analysis
- Business Insights
- Interactive Data Filtering

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/amansoni46/Data-Analytics.git
```

### 2. Open the project folder

```bash
cd Data-Analytics
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the dashboard

```bash
python Data_Analytics.py
```

Then open the local URL shown in the terminal.

## 🌐 Deployment

The dashboard is deployed using **Render** and is available online through the Live Demo link above.
